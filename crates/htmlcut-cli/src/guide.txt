htmlcut - extract exactly what a contract declares from an HTML document, or refuse

Usage:
  htmlcut outline [FILE] [--select CSS] [--depth N] [--max-lines N] [--attrs]
  htmlcut get <CSS> [FILE] [--all] [--read READING] [--raw]
  htmlcut run <CONTRACT-JSON> [FILE] [--raw]
  htmlcut run --from-file <CONTRACT.json> [FILE] [--raw]
  htmlcut schema [-o DEST] [--timeout SECONDS] [--max-output-bytes N]

FILE defaults to standard input. Get/run return compact JSON; outline prints text
and schema prints JSON. A refusal before publication writes no result bytes.
Diagnostics are one JSON line when delivery succeeds; reporting is best effort.
A closed stdout pipe is silent success; other delivery failures can expose a prefix.
Use -o for atomic regular-file output; stdout, pipes and devices are direct.

Workflow from a source checkout (substitute your snapshot for FILE):
  htmlcut outline conformance/contract/04-records/page.html --select 'article.product'
  htmlcut get 'h1' conformance/contract/04-records/page.html
  htmlcut run '{"expect":[{"select":"h1","equals":"All products"}],"select":"article.product","match":"all","min":3,"max":3,"fields":{"title":{"select":"h3 a","read":"attr:title"},"price":{"select":".price","pattern":"^£(?<value>[0-9]+[.][0-9]{2})$"},"badge":{"select":".badge","match":"optional"}}}' conformance/contract/04-records/page.html

Contract node (a bare selector string means {"select": that string}):
  select    CSS matched inside the enclosing match; omitted = inherited range; attrs/URLs use anchor
  match     one (default) | optional (null when absent) | all (array; min, max)
  nth       take the Nth match instead of requiring exactly one
  where     keep matches satisfying predicates: [{"select":"th","equals":"UPC"}]
  until     CSS boundary: following siblings up to it, within inherited membership
  fields    {name: node} - one record per match, with 1 to 64 fields
  read      text (default) | text-content | outer-html | attr:NAME | url:NAME
  exclude   [CSS] subtrees left out of text, text-content and outer-html
  equals    the value must equal this string
  pattern   the value must match this regex; (?<value>...) keeps only that group
  expect    predicates that must hold where this node is evaluated
Predicate: {select, read, equals | pattern, min, max}; the count defaults to exactly 1.
An attr:NAME predicate requires the attribute even without a value test. Template
contents stay outside selection; reading a template itself returns its contents.
Selectors: CSS structural selectors, :not/:is/:where/:has, :nth-*; no :checked, :link
or :lang (use attributes). Patterns: Rust regex, Unicode, no look-around.

Options:
  --base-url URL          base for url:NAME readings; a <base href> is honoured
  --encoding LABEL        override document declaration; a BOM takes precedence
  -o, --output FILE       atomic regular files; - is stdout; follows symlinks
  -r, --raw               scalar strings; lists require LF-free items
  --timeout SECONDS       invocation deadline including input/output; default 10
  --max-nodes N           default 2000000
  --max-input-bytes N     default 67108864
  --max-reading-bytes N   per transformed source scalar; default 67108864
  --max-output-bytes N    default 67108864
  --help, -h, help        top-level guide; COMMAND --help shows its grammar
  --version, -V           print the engine version

Exit status: 0 success, 2 invalid arguments or contract, 3 refused (the document
does not satisfy the contract or raw list cannot preserve framing), 4 limit exceeded, 5 input or output failure,
6 internal error.

Common options apply to outline/get/run; --raw applies only to get/run.
Schema supports only output and timeout. Use COMMAND --help for exact placement.
Contract stdin: run --from-file - page.html, with a distinct HTML source.
FILE URLs require successful external acquisition first; see docs/contract.md.
Schema is authoring structure validation; integer tokens must be 1, not 1.0/1e0/-0.

Output ceilings admit the complete canonical export including final LF. Raw output
also obeys canonical JSON admission; optional null needs five canonical bytes
though its raw export is empty. Each invocation has one absolute deadline.
